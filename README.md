# MeowTown
A Game for who love cat and don't want to work. 

策划_draft：
- 小镇里可以赚鱼干（货币）。但是只有猫猫能去赚。人和猫都会消费。
- 玩法：
	- 你有一只猫。它会有一份/几份工作。
	- 工作会影响它的心情
	- 对你的好感度增加后猫猫会给你小鱼干。具体给多少由心情+对你的好感度决定
	- 撸猫、陪猫猫玩游戏、照顾小猫、给它买东西都会增加好感度。
	- 节日、特殊活动中人可以和猫猫一起赚小鱼干；其他时候只有猫才能打工赚小鱼干
	- 猫打工的时候不在家。无法陪猫玩。
	- 如果不满意猫猫现在的工作可以跟它提建议（让它辞职/换工作/多干几份工作）。
	- 撸跟猫关系不好的猫自己的猫会发现，会生气不和你玩/一直粘着你(看猫性格）。长此以往会掉好感度（如果家里有可以清洗味道的家具，使用后就不会被发现）
	- 小游戏
		- 猫猫会有自己喜欢的小游戏，每只猫都不一样。
		- 如果陪它玩小游戏会得到鱼干奖励。具体多少由它的心情+对这个游戏和你的喜爱程度决定
- 日常剧情：
	- 人主要的剧情就是等猫猫打工回来和它玩。会有猫猫打工日志（像青蛙的旅行日志那样）。
	- 猫会有猫朋友。但是你使它最好的朋友。
	- 你和你的猫一起在猫猫小镇幸福地生活。
	- 可以撸猫，可以不只撸自己的猫。
- 消费：
	- 猫不需要花小鱼干买饭吃。
	- 可以买家具、礼物（装饰品）、玩具等。
- 罚款：
	- 可以撸猫但是撸工作中的猫可能会被罚款(如果被发现了会罚款，没被发现则会有双份的好感）
	- 交不起罚款自己的猫就要过去打工
